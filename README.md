## Projects

Course projects will be added here as they are completed. Each project will have its own numbered folder, documentation, source files, data-access instructions, results, and limitations.

## Repository approach

The `lessons` directory contains concise, exam-ready notes organized by class session. Each lesson records my understanding of the concepts, mathematical formulations, interpretations, and important caveats discussed in class.

Practical projects are kept separate from lesson notes so that their code, data, experiments, and documentation can evolve independently.
